Hitech HRX Implementation

Complete Step-by-Step Installation & Configuration Guide

This document provides a detailed walkthrough for setting up the Hitech HRX management system. Follow each step carefully to ensure a successful implementation.

🛠️ System Requirements

Before proceeding, ensure your server environment meets the following specifications:
  • PHP Version: 8.2 or higher
  • Database: MySQL 8.0+ / MariaDB 10.4+
  • Web Server: Laragon, XAMPP, Apache, or Nginx
  • Memory Limit: 256MB minimum
  • Extensions: BCMath, Ctype, Fileinfo, JSON, Mbstring, OpenSSL, PDO, Tokenizer, XML

🚀 Installation Steps

1
Source Preparation

Download the HRX source code and extract it to your web directory. For example:

  • Windows (Laragon): C:\laragon\www\hrx
  • Windows (XAMPP): C:\xampp\htdocs\hrx
  • Linux: /var/www/html/hrx
2
Dependency Management

Open your terminal/command prompt in the project root and install the required PHP and JavaScript packages:

composer install --no-dev --optimize-autoloader
npm install
3
Environment Configuration

Create your environment file by copying the example template:

cp .env.example .env

Open the .env file in a text editor and update the following settings:

  • DB_DATABASE: The name of your database.
  • DB_USERNAME: Your database username (e.g., root).
  • DB_PASSWORD: Your database password.
  • APP_URL: Set this to your local or live domain (e.g., http://localhost:8000).
4
Application Initialization

Initialize the application security keys and set up the database structure:

php artisan key:generate
php artisan migrate --seed

The --seed flag is important as it populates the database with initial administrative accounts and settings.

5
Storage & Assets

Link the application storage folder to the public directory and build the frontend assets:

php artisan storage:link
npm run build
6
Launching Services

To run the application locally, you need to start the main server and the real-time notification engine:

php artisan serve App Server
php artisan reverb:start Real-time Messaging
